# DMR Studio 支持哪些直播平台？

[返回首页](../README.md) · [零基础录播教程](quick-start.md) · [English](platforms.en.md)

本页介绍 **DMR Studio v1.0** 的直播录制、弹幕录制和自动投稿平台适配范围。适合搜索 **B站录播软件、抖音直播录制、虎牙录播、斗鱼直播录制、弹幕渲染工具** 的用户。

**注意：平台适配代码存在，不代表平台最新接口已完成全面实测。** 直播站点的验证策略、网络限制与接口随时可能变化。

## 直播间与弹幕适配

| 直播平台 | 直播 API 适配 | 弹幕接口适配 | 使用说明 |
|---|---|---|---|
| B站（Bilibili） | 有 | 有 | 以实际直播间连接及录制结果为准 |
| 抖音（Douyin） | 有 | 有 | 验证策略、接口可能变化 |
| 虎牙（Huya） | 有 | 有 | 以实际可访问直播间为准 |
| 斗鱼（Douyu） | 有 | 有 | 以实际可访问直播间为准 |
| Twitch | 有 | 有 | 网络和平台接口限制可能影响录制 |
| 网易 CC | 保留历史代码 | 保留历史代码 | 当前程序界面标记直播服务停运，不能作为仍可录制的平台宣传 |

其他链接可能进入默认解析或被标记为「未验证平台」，**不代表支持所有直播网站**。

## 直播录制、视频下载、自动投稿的区别

- **直播录制**：根据直播状态与任务设置录制直播流。
- **弹幕录制与渲染**：保存平台允许获取的弹幕，并按设置生成弹幕版视频。
- **视频下载任务**：与直播录制不同；任务界面注明 B站视频链接可使用弹幕下载与相应处理功能，其他来源不一定具有同样能力。
- **视频自动投稿**：任务界面可选择「不上传、B站、YouTube」。**支持 YouTube 投稿不等于支持录制 YouTube 直播**，需要区别看待。

初次使用建议先阅读 [Windows 直播自动录制教程](quick-start.md)，优先确认有视频文件生成，再测试弹幕、渲染及投稿。平台兼容性反馈请使用 [GitHub Issues](https://github.com/jiabenguiyin/DMRStudio/issues)，不要公开 Cookie 或 Token。
