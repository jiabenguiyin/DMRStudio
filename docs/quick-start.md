# DMR Studio 新手教程：Windows 直播自动录制与弹幕录制

[项目主页](../README.md) · [平台适配说明](platforms.md) · [English](quick-start.en.md)

适用版本：**DMR Studio v1.0（Build 18）**，Windows 桌面版，支持简体中文和 English。以当前安装版的实际界面为准。

## 1. 安装与初次启动

1. 从 [GitHub Releases](https://github.com/jiabenguiyin/DMRStudio/releases) 下载官方 Windows 安装包。
2. 安装、启动 DMR Studio，首次使用可点击「新手引导」。
3. 「首页」包含运行控制台、录制引擎状态及任务统计。
4. 切换语言：打开「系统设置 → 界面语言」，选择 English 后点击「保存设置」。

若 Windows SmartScreen 提示发布者未知，请先确认文件来自本仓库正式 Release，不要随意执行来历不明的改包。

## 2. 新建直播录制任务

1. 打开「录播管理」，点击「新建任务」。
2. 填写「任务备注」（任务名称）和「直播链接」；例如以下直播间地址形式：
   - B站：`https://live.bilibili.com/123456`
   - 抖音：`https://live.douyin.com/123456`
   - 虎牙：`https://www.huya.com/123456`
   - 斗鱼：`https://www.douyu.com/123456`
   
   **这些数字仅用于演示 URL 格式，不是真实可用的房间号。** 请粘贴你实际访问过、且有权录制的直播间链接。
3. 设置「文件输出目录」：确认 Windows 当前用户有写入权限，且磁盘空间足够。
4. 启用「录制视频」；需要直播弹幕时再启用「记录弹幕」，弹幕能否取得取决于平台接口。
5. **初次测试建议只录视频**：暂不开启「录制后自动渲染弹幕版」，并将「投稿到」设为「不上传」，确认成功后逐项添加其他流程。
6. 保存任务并返回「录播管理」。

软件有 B站、抖音、虎牙、斗鱼等直播与弹幕适配实现，但不保证每个直播间或每种清晰度始终可用。请参阅[平台适配说明](platforms.md)。

## 3. 启动引擎、检查录制

1. 在「录播管理」或首页点击「启动引擎」。
2. 在直播监控页面检查任务是否启用、主播是否开播，以及任务是否正在录制。
3. 主播未开播时，任务可能等待后续状态检测；网络和第三方平台访问限制会影响结果。
4. 直播开播后，检查输出目录中是否产生**实际录像文件**；同时可查看状态和日志，不要只凭任务已创建判断录制成功。
5. 需要控制长时间录像文件时，可在任务「高级设置」中调整「分段时长（秒）」。分段录制不等于智能剪辑精彩片段。

## 4. 弹幕渲染与自动投稿

- **弹幕录制**：根据需要开启「记录弹幕」；不同平台的弹幕接口能力可能不同。
- **弹幕渲染**：在「弹幕渲染调节」调整字号、透明度、滚动速度与占屏区域；任务可开启「录制后自动渲染弹幕版」。
- **渲染中心**：查看渲染队列、可渲染视频、失败记录、上传进度与上传结果。
- **自动投稿**：任务的「投稿到」有「不上传 / B站 / YouTube」选项。使用前须在「上传账号」完成授权并确认自己有权上传相关内容。YouTube 上传可能受 Google API 授权、审核和配额限制。

## 5. 录播失败？优先排查这些问题

| 现象 | 建议检查 |
|---|---|
| 创建任务后没有录像 | 录制引擎是否启动、任务是否启用、主播是否开播、直播链接是否有效 |
| 直播间信息获取失败 | 在浏览器打开直播链接，检查网络、验证和平台访问限制 |
| 平台显示「未验证」 | 这不是经过完整实测保证的平台，请留意软件提示 |
| 只有视频没有弹幕 | 是否开启「记录弹幕」，该平台当前是否能提供弹幕 |
| 未自动渲染 | 任务是否开启渲染、源文件与弹幕数据是否存在、渲染中心是否报错 |
| 投稿失败 | 上传账号授权、内容权限、平台审核及配额 |

若仍无法解决，请在 [Issues](https://github.com/jiabenguiyin/DMRStudio/issues) 提供 Windows 版本、软件版本、复现过程及脱敏日志。**切勿公开 Cookie、Token、密钥和账户隐私信息。**

## 容易混淆的概念

DMR Studio 用于**直播录播、开播自动录制、分段录像、弹幕录制和弹幕渲染**，可为制作直播切片提供素材，但 **分段录制不等于自动发现高光片段**。请勿把本版宣传成具备全自动智能切片能力的工具。
